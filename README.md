# Programme Traning Description  -
Recent advances in geo spatial technologies and computational methods have enabled python and AI /ML  to serve as powerful enablers for geodataanalysis . In this study , two structured outreached programmes conducted by the indian institute of remote sensing , isro were undertaken to demonstrates disciplined workflows for geospatial data handling and intelligent analysis .

The 133rd Outreach programme -Geodata processing using python introduced participants of fundamentals of remote sensing & GIS , Jupyter Notebook , python basics , raster data processing , classification ,changed detection , and vector data visualization . the 144th Outreach programme - AI/ML for geodata analysis extended the scope to suprevised and unsupervised learning , deep learning architectures ( CNN,RNN, transfer learning ) and hands on exercises for geodata applications .
together , these programmes illustrates a complete pipelines  : from raw geospatial obeservations to statically defensible insights and intelligent features extraction . The combined curriculum emphasizes evidence-driven descision support in geoinformatics , bridging classicial geodata processing with modern AI /ML approaches .
